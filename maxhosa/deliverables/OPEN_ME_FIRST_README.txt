MAXHOSA AFRICA APP — OFFLINE CONCEPT DEMO
==========================================

What this is
------------
One HTML file, MAXHOSA_AFRICA_App_Offline_Demo.html, that runs the concept
app in a web browser with no internet and no installation.

  Concept demo — sample products, sample courier, no real purchase/delivery.

Nothing you do in it creates an order, takes a payment, books an appointment,
holds an event place or sends a message. Products, prices, sizes, stock,
orders, courier events and event fixtures are invented sample data. The 24
images are verified concept assets, not approved product photography; one
more photograph (the sunset event) was supplied by the client for events.

What you can try
----------------
  Home, Shop (search, filters, sort), a product page (gallery with zoom, sizes,
  size guide), Saved, the Bag and a simulated checkout, a styling appointment
  enquiry, and the delivery tracker (with "Advance demo status", a simulated
  same-day courier map, delivery problems and stale-data states).

  Events and fixtures: Discover > Open the events calendar. Swipe the month,
  tap a day, filter by city, RSVP (or join a waitlist, or request an
  invitation), add an event to your calendar (saves an .ics file), invite a
  friend, and shop the event edit.

  It is built to feel like a phone app: drag sheets by their handle and flick
  them away, swipe from the left edge to go back, pinch or double-tap photos.

How to open it
--------------
macOS
  1. Save the .html file (or unzip the package) to Downloads or the Desktop.
  2. Double-click it in Finder. It opens in your default browser.
  3. If macOS warns you, right-click the file > Open With > Safari or Chrome.

Android
  1. Download the .html file, or download the .zip and extract it.
  2. Open the Files app (or "My Files") > Downloads.
  3. Tap the .html file and choose Chrome (or another browser) if asked.
  4. If your file manager will not open HTML directly, open Chrome and type
     file:///sdcard/Download/ in the address bar, then tap the file.
  File managers differ between phone makers; one of the steps above usually
  works, but not every phone behaves the same way.

iPhone / iPad
  Save the file to the Files app, then open it — Files shows a preview; use
  Share > Open in Safari if the preview does not run it.

WhatsApp
  WhatsApp is a way to send the file, not a way to run it.
  - Send the .html (or the .zip) as a Document, not as a link or a photo.
  - The person receiving it downloads it, then opens it from their Files or
    Downloads app in a browser, as above.
  - WhatsApp's own preview may not run the demo. That is expected.

Good to know
------------
  - Works offline. Links to maxhosa.africa are optional and say
    "External link requires internet" when you choose them.
  - Your bag, saved pieces and sample orders are remembered on this device
    if the browser allows it; some browsers block storage for local files, and
    then the demo simply forgets when you close it. Account > Reset demo
    clears everything.
  - Respects your device settings: dark mode, larger text, Reduce Motion and
    Reduce Transparency.

This file is a presentation prototype. It is not the native app (which is
distributed through the App Store and Google Play) and not an installable
web app (which needs to be hosted over HTTPS).
